# DECISIONS.md

El autor mantiene un diario de decisiones de diseño (con el razonamiento, las
mediciones y el consumo de cada corrida) como notas de trabajo locales. **No se
publica en este repositorio.**

Dónde está documentado el diseño vigente:

- `docs/ARCHITECTURE.md`: capas, principios y decisiones de arquitectura.
- `docs/AI_PROVIDERS.md`: motores de IA, qué consume cada uno y cómo agregar otro.
- `docs/DATA_MODEL.md` y `docs/SYSTEM_INVARIANTS.md`: esquema e invariantes.
- `docs/SECURITY.md`: manejo de datos personales y de entradas externas.

Los comentarios del código que remiten a este archivo citan ese diario; el
razonamiento esencial de cada módulo está en su propio encabezado.
