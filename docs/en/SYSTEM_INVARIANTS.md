# WhatsApp Memory Search

## Purpose

This document defines the fundamental rules that govern the system.

These rules are invariants: they must always hold, regardless of the
implementation, the technology used or the AI model employed.

Every new feature must respect these rules.

---

# Evidence

### SI-001

Evidence is the single source of truth.

---

### SI-002

Every Message is immutable.

---

### SI-003

A Message can never be deleted.

---

### SI-004

An Attachment can never exist without a Message.

---

### SI-005

Every Message belongs to exactly one Conversation.

---

### SI-006

Every Message has exactly one Participant.

---

### SI-007

Evidence can never be modified as a result of an AI analysis.

---

### SI-008

Evidence always keeps its original content.

---

# Conversation

### SI-009

A Conversation is the main container of the system.

---

### SI-010

All domain objects must belong, directly or indirectly, to a Conversation.

---

### SI-011

Participants belong to a single Conversation.

---

# Knowledge

### SI-012

Every Event belongs to a single Case.

---

### SI-013

A Case can contain multiple Events.

---

### SI-014

An Event can be backed by one or several Messages.

---

### SI-015

Every Insight must be backed by evidence.

---

### SI-016

An Insight never modifies the evidence.

---

### SI-017

Relationships never create evidence.

They only describe existing relationships.

---

# Artificial Intelligence

### SI-018

AI never modifies the evidence.

---

### SI-019

Every Analysis must state the model used.

---

### SI-020

Every Analysis must state the prompt version.

---

### SI-021

Every Analysis must state its generation date.

---

### SI-022

Every Analysis can be regenerated.

---

### SI-023

Every Analysis must be deletable without affecting the evidence.

---

### SI-024

Every conclusion generated by AI must state its evidence.

---

### SI-025

Every probabilistic conclusion must state a confidence level.

---

### SI-026

No Analysis represents an absolute truth.

---

# Embeddings

### SI-027

Embeddings never represent knowledge.

---

### SI-028

Embeddings can be regenerated at any time.

---

### SI-029

Deleting Embeddings never affects the evidence.

---

# Processing

### SI-030

Every Message must be reprocessable.

---

### SI-031

Processing must be idempotent.

---

### SI-032

The failure of a stage never deletes information.

---

### SI-033

Pipeline stages must be independent.

---

### SI-034

Processing never blocks the persistence of messages.

---

# Search

### SI-035

Every search must prioritize evidence over interpretation.

---

### SI-036

Semantic searches never replace exact searches.

---

### SI-037

Every answer must be reconstructible from the evidence.

---

# Assistant

### SI-038

The Assistant never modifies the evidence.

---

### SI-039

The Assistant never sends messages automatically.

---

### SI-040

Every external action requires the user's explicit authorization.

---

### SI-041

The Assistant uses exclusively the Search Layer to retrieve information.

---

# Persistence

### SI-042

Every entity has a unique, immutable identifier.

---

### SI-043

Evidence never uses soft delete.

---

### SI-044

Every piece of derived data can be regenerated.

---

### SI-045

Every important operation must be traceable.

---

# Evolution

### SI-046

The system must allow incorporating new AI models without modifying the
domain.

---

### SI-047

The system must allow fully rebuilding the knowledge.

---

### SI-048

Domain rules are independent of the infrastructure.

---

### SI-049

Replacing a technology must not modify the domain model.

---

### SI-050

Every new feature must respect the rules defined in this document.
