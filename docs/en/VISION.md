# Conversation Memory Assistant

[Español](../VISION.md) · **English**

## Vision

Conversation Memory Assistant is a conversational memory system designed to
preserve, organize and analyze a specific WhatsApp conversation.

The system's main goal is not to act as a chatbot, but to become a
permanent, intelligent memory of the conversation.

Every message, received or sent, is a piece of historical evidence that must
never be modified. From that evidence the system builds different layers of
knowledge that allow intelligent queries, detecting behavior patterns,
generating summaries and assisting future interactions.

The original conversation is always the source of truth.

Every interpretation made by artificial intelligence is treated as derived
knowledge and can be recomputed in the future without altering the original
evidence.

---

## Goals

- Keep a complete copy of the WhatsApp history.
- Automatically sync new messages.
- Allow queries in natural language.
- Quickly find historical information.
- Detect important events.
- Identify communication patterns.
- Analyze the tone of conversations.
- Extract activities and commitments.
- Generate reminders.
- Assist in drafting replies when the user asks for it.

---

## Principles

### Evidence never changes

The original messages are immutable.

The system will never modify them.

---

### Every conclusion must be verifiable

Answers generated by AI must always be able to point to the messages used to
reach the conclusion.

---

### AI interprets, it does not invent

If the system does not have enough information it must say it cannot answer.

It must never fill in missing information with assumptions.

---

### Knowledge is replaceable

Analyses made by AI can be regenerated using newer models.

The original messages never can.

---

### The user stays in control

The system will never reply to messages automatically without explicit
authorization.

It will never send information to third parties.

It will never delete evidence.

---

## Initial scope

The first version focuses only on one specific WhatsApp conversation.

---

## Future scope

In later versions the system may:

- Manage calendars related to the conversation.
- Remember important activities.
- Generate proposals for formal messages.
- Assist in the communication between both parties.
- Sync conversations in real time.
- Incorporate new sources of information.

---

## Philosophy

Conversation Memory Assistant does not aim to replace the user's memory.

It aims to organize it, preserve it and make it queryable through artificial
intelligence.
